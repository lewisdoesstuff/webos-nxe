NXE

A webOS home app that recreates the look and motion of the late-2008 console dashboard on a rooted LG TV: a row of panes you move through with the remote, a boot sequence, toasts, a Guide overlay, HDMI input previews and a Steam friends list.

Notes

  • Needs a rooted TV running webOS 23 or later.
  • Ships with an original default theme. On first launch the app can download an optional retail-style theme add-on and install the Home button hook.
  • Not affiliated with Microsoft, LG or Valve.
